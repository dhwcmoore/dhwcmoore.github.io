Technical Profile

Formal verification specialist working across machine-checked proof, RTL formal verification, executable checking and assurance architecture. My current work combines Rocq/Coq, SystemVerilog/SVA, Yosys/SMT, OCaml and Python. I build formal specifications, prove kernel results, analyse counterexamples, extract or implement small verification cores, connect them to reproducible tooling, and document the assumptions and residual trust that remain outside the proof.

Current public work includes a security-critical DMA access-control fabric with inductive and bounded formal results, a DO-333-oriented assurance reconstruction, a structural-admissibility library with extracted OCaml monitoring components, proof-carrying audit-warrant verification, and a certificate architecture that separates untrusted generation from independent verification.

Selected Verification Projects

Security-Critical DMA Access Control

Creator · SystemVerilog · SVA · Yosys/SMT · Rocq · public CI-backed repository

  • Designed and formally analysed a stateful DMA access-control fabric with CPU and DMA requesters, one protected region, programmable DMA authority, locking, reset, arbitration and one outstanding transaction.
  • Developed explicit security requirements, normative SVA properties and executable checkers. The forwarding-authorisation boundary is proved inductively for all steps under the declared model; registered memory-effect and configuration-admissibility properties are reported separately as bounded to depth 12.
  • Built three controlled defect campaigns covering authorisation bypass, stale/reset authority and finite-width address-range overflow. Each defective variant is formally detected with a preserved counterexample trace.
  • Built a machine-readable verification ledger, evidence audit, deterministic tool bootstrap and GitHub Actions release gate that distinguish proof strength, assumptions, requirements and open obligations.

Proof-Carrying Exactness

Creator · proof-carrying verification · Python · exact rational arithmetic · public repository

  • Built a pure certificate verifier that checks already-produced certificates without importing the untrusted search and discovery machinery used to construct them.
  • Separated an untrusted generator for four verdict classes from the production verifier, with certificate bytes released only after independent verification succeeds.

Professional Profile

Formal methods and verification researcher developing independent assurance systems for distributed data, automated reasoning, sensor evidence, and consequential computational pipelines.

I build systems in which a program may propose a result but is not trusted to certify its own work. My projects combine machine-checked mathematics in Rocq, executable OCaml and Python verification, proof-carrying evidence, explicit failure witnesses, and reproducible test suites.

Current work concentrates on a practical question: what is a computational result actually entitled to claim, given the evidence, representation, assumptions, and trust context available to it?

Open to formal verification, assurance, systems research, auditable AI, distributed-systems, and verification-architecture roles.

Selected Engineering and Verification Projects

Proof-Carrying Stream Exactness

Creator and Lead Developer | Python, Rocq

Developing an independent verification system for finite data transfers.

  • Distinguishes EXACT, UNDERDETERMINED, OBSTRUCTED, and INADMISSIBLE rather than collapsing materially different failures into pass/fail.
  • Binds certificates to the evidence bundle, transfer identity, assurance level, and trust context.
  • Uses a certificate generator and a separately implemented verifier so that certificate production does not constitute its own authority.
  • Detects missing, conflicting, out-of-range, malformed, unauthorised, or insufficient evidence.
  • Uses differential campaigns to compare executable assessment with independent certificate verification over derived evidence lattices.
  • Rocq formal core and executable implementation are deliberately kept as distinct assurance layers; formal-executable correspondence is not claimed until proved.

Proof-Carrying Exactness

Creator | Python, Rocq

Designed a certificate architecture for finite exact problems.

  • Uses explicit evidence to distinguish exact, underdetermined, obstructed, and inadmissible cases.
  • Implements deterministic certificates and independent verification.
  • Uses exact arithmetic where approximation would otherwise obscure the status of a claim.
  • Rejects altered or unsupported evidence rather than silently repairing it.

VeriBound-FCE

Private Research Prototype | Python, OCaml, Rocq

Developed an assurance layer for proposed sensor-fusion results.

  • Recomputes numerical claims rather than trusting upstream output.
  • Checks independently generated evidence and rejects altered certificates.
  • Detects global inconsistencies that can remain invisible when reports are examined only pairwise.
  • Designed to sit beside an existing tracking or fusion system rather than replace it.

Structural Admissibility Library

Creator | Rocq, OCaml

Developed a machine-checked framework for determining whether an observation preserves enough information to support a specified claim.

  • Forty-one Rocq source modules.
  • Applications explored in distributed consensus, GPU execution, physical sensing, and runtime monitoring.
  • Formalises a central engineering alternative: when an observation cannot determine the desired claim, either weaken the claim or improve the observation.

Regional Obstruction Calculus and CycleDebt

Creator | Rocq, OCaml, Python, HELICS

Developed formal and executable methods for detecting global inconsistency hidden by locally acceptable observations.

  • Machine-checked constructive results in Rocq.
  • Executable OCaml and Python verification paths.
  • Concrete separating witnesses when local evidence cannot be assembled into a valid global result.
  • CycleDebt provides a runnable cyclic-system diagnostic using exact integer and rational arithmetic.
  • HELICS co-simulation demonstrates application to distributed infrastructure models.

Lift-Descent Exactness

Creator | Rocq

Developed a constructive exact-linear-algebra framework separating two fundamentally different failures: no admissible solution exists, or several admissible solutions remain and disagree about the requested value.

The development provides constructive obstruction and ambiguity witnesses and analyses which conclusions survive changes of representation.
